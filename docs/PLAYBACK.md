# 播放器行为与状态规则

本文档定义播放器对用户可见的播放、进度保存和恢复语义。实现细节可以调整，但不得在未更新本文档的情况下改变这些行为。

## 核心概念

- **当前播放会话**：播放器最近一次使用的临时队列、当前作品、时间点和播放方式。搜索结果、手动队列以及来自内容集合的队列都可以成为当前播放会话。
- **内容集合**：具有稳定身份和播放顺序的 UP 主全部作品、合集、系列或自定义播放列表。搜索结果和手动队列不属于可记录集合进度的内容集合。
- **全局检查点**：用于“继续上次播放”，恢复用户离开播放器前的完整播放会话。
- **集合检查点**：每个内容集合最多保存一个位置，用于“继续听此 UP 主全部作品/合集/系列/播放列表”。它不是每个作品各自的历史进度。

## 全局继续播放

全局检查点保存当前队列快照、队列来源、当前作品身份、队列位置、播放时间点、播放顺序和更新时间。

- 播放器必须在队列或当前作品变化时立即保存会话结构。
- 播放过程中定期保存时间点；暂停、拖动进度和切换作品时立即保存。
- 浏览器或离屏播放器重新启动后，必须先恢复队列和作品，再等待媒体可定位，完成并验证跳转后才开始播放。
- 恢复失败时必须给出明确反馈，不得静默从头播放并假装恢复成功。
- 打开扩展不会自动出声；恢复播放必须由用户主动触发。

## 集合继续播放

每个 UP 主的全部作品、合集、系列和自定义播放列表各自保存一个轻量检查点，包含集合身份、当前作品身份、当时的序号、作品内时间点、播放顺序、更新时间和完成状态。

- 集合检查点随属于该集合的播放会话同步更新。
- 搜索结果和手动队列只更新全局检查点，不更新任何集合检查点。
- 收藏只是合集或系列的访问入口，必须与原始栏目共享同一个集合检查点。
- 恢复集合时重新读取当前内容，优先按作品身份定位，并采用检查点记录的播放顺序。保存的序号只用于作品已不存在时兜底。
- 自定义播放列表重命名不影响检查点；列表被删除时一并删除对应检查点。
- 播放列表重排后仍优先定位原作品，后续播放采用列表当前顺序。

## 稳定身份

集合检查点使用以下作用域键：

```text
all:<UP主UID>
season:<UP主UID>:<合集ID>
series:<UP主UID>:<系列ID>
playlist:<播放列表ID>
```

作品使用稳定的 BV 号或运行时作品 ID 定位。恢复时不得仅依赖容易随排序和内容变化而改变的数组序号。

## 完成和异常处理

- 保存位置距离当前作品结尾不足 5 秒时，继续播放应进入下一首。
- 最后一首正常播放结束后，集合检查点标记为已完成；界面显示“重新播放”，不再显示无意义的末尾进度。
- 检查点作品仍存在时，从该作品的记录时间点继续。
- 检查点作品不存在时，使用保存序号选择当前列表中最接近的作品，并向用户说明原作品已不可用。
- 集合为空、身份无效或无法构造队列时，清除或忽略无效检查点并给出反馈。
- 时间点必须限制在有效媒体时长内；媒体定位必须等待并验证 `seeked` 或等价结果。

## UI 与交互

### 全局入口

固定底部播放栏是全局继续播放的主要入口。存在检查点但后台媒体尚未载入时，底栏展示上次作品、队列来源和时间点，主播放按钮执行恢复。UP 主资料区不放置语义含混的全局“继续播放”按钮。

### 全部作品、合集、系列和收藏卡片

- 没有检查点时显示“播放全部”。
- 存在未完成检查点时，主播放操作为“继续播放”，并显示“已听至第 N / M 个作品 · MM:SS”。
- 已完成时显示“重新播放”。
- 收藏卡片和原始栏目卡片展示相同进度。

### 详情页和自定义播放列表

存在未完成检查点时，详情页展示当前作品名称、序号和时间点，并同时提供主操作“继续播放”和次操作“从头播放”。没有检查点时只提供“播放全部”；已完成时提供“重新播放”。

## 设置与数据生命周期

- “记住播放位置”默认开启，并同时控制全局检查点和集合检查点。
- 关闭后不再记录可恢复的作品内时间点，也不应展示集合继续播放入口。
- 删除自定义播放列表时删除对应集合检查点；取消收藏不删除原合集或系列的检查点。
- 检查点只保存在当前浏览器的扩展本地存储中，不进行跨设备同步。

## 验收场景

- 暂停后关闭并重新打开扩展，继续上次播放能够恢复队列、作品和近似时间点。
- 浏览器完全退出后重新启动，在线音源和本地缓存音源都能恢复并验证跳转。
- 先播放某个系列，再播放手动队列；全局入口恢复手动队列，系列入口仍恢复原系列位置。
- 从 UP 主主页播放“全部作品”后重新进入时，可以继续到同一作品和时间点。
- 从 UP 主主页和收藏页进入同一合集时，两处进度一致。
- 系列新增作品、切换排序或播放列表重排后，仍优先恢复原作品。
- 删除当前作品后，使用保存序号安全兜底并提示用户。
- 距作品末尾不足 5 秒时进入下一首；最后一首结束后集合显示已完成。
- 关闭“记住播放位置”后，不再创建或展示可恢复检查点。
